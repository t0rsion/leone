# v0.8 claim boundary

Recorded 2026-08-24 before v0.8 implementation.

## Adjacent work

QSpec combines a low-precision draft path with higher-precision exact
verification. ML-SpecQD uses recursive quantized drafts. DP-LLM changes layer
precision at runtime. SpecKV selects proposal width from compression signals.
Bit-by-Bit trains nested integer grids for several deployment precisions.

These results prevent Leone from claiming novelty for quantized drafting,
runtime precision selection, adaptive proposal width, or nested precision by
itself.

## Leone claim

The v0.8 release claim is narrower. It covers exact adaptive composition of
distribution-valued history proposals, measured action selection, append-only
evidence, and a portable progressive-code contract.

No public first claim is authorized by this note. A public novelty claim needs
an archived second-pass search over DBLP, Semantic Scholar, GitHub, and patents.
