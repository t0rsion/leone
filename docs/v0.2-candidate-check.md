# Check the v0.2 candidate

Run the publication gate from a clean candidate commit:

```sh
scripts/check-v0.2-release.sh
```

The command runs the source hygiene, dependency, static, CPU, CUDA, oracle,
documentation, and archive gates. It then extracts both archives and checks
their version, commit, manifest, linkage, and execution. A second build must
produce the same archive checksums.

The extracted binary must return typed HTTP errors for malformed JSON, unknown
models, and unknown routes. It must remain available after those requests.
The installed binary must load its packaged plan from an unrelated directory.

The gate rejects tracked private-work artifacts, credentials, personal paths,
models, full logits, runtime search paths, and unresolved libraries.

The command needs an idle NVIDIA GPU and both release-gated quantized models
under `models/`. It does not tag, push, install, or publish anything.
